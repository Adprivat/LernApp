  <action>
Create `src/lib/errorHandler.ts` with the following three exported functions:

1. **`getErrorMessage(err: unknown): string`**
   - If `err` is an `Error` instance, return `err.message`
   - If `err` is a string, return it directly
   - If `err` is an object with a `.message` string property (covers Supabase PostgrestError), return that
   - Otherwise return a generic fallback: `'Ein unerwarteter Fehler ist aufgetreten'`

2. **`isSupabaseError(err: unknown): err is { message: string; code: string; details: string; hint: string }`**
   - Type guard that checks if `err` is a non-null object with string `message` and `code` properties
   - This matches Supabase's PostgrestError shape

3. **`handleSupabaseError(error: { message: string; code?: string; hint?: string } | null, fallback?: string): string`**
   - If `error` is null/undefined, return empty string (no error)
   - If `error.hint` is `'already_accepted'`, return `'Diese Aktion ist nicht mehr verfuegbar.'`
   - If `error.hint` is `'unauthorized'`, return `'Nicht autorisiert.'`
   - If `error.message` includes `'duplicate key'`, return `'Dieser Eintrag existiert bereits.'`
   - If `error.message` includes `'not found'` or `'no rows'`, return `'Eintrag nicht gefunden.'`
   - If `error.message` includes `'Invalid login credentials'`, return `'Falscher Benutzername oder Passwort'`
   - If `error.message` includes `'already registered'`, return `'Benutzername bereits vergeben'`
   - Otherwise return `fallback` parameter if provided, or `error.message`

All messages in German consistent with the app's existing UI language. No external dependencies needed.
